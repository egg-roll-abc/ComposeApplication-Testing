## 二、三大自动化压力场景测试流程

### 场景1：账单列表持续滑动压力测试

| 项目 | 说明 |
| --- | --- |
| 自动化逻辑 | 模拟器自动循环上下滑动账单列表，单次滑动间隔0.5s，持续加压3min |
| 数据采集 | 每10s执行 dumpsys meminfo 采集应用PSS内存 |
| 输出文件 | 01_滑动列表_性能日志.csv |
| 数据表现 | 内存基线平稳小幅震荡，仅滑动加载新列表项瞬时抬升，GC后快速回收 |

### 场景2：页面循环切换压力测试

| 项目 | 说明 |
| --- | --- |
| 自动化逻辑 | 自动点击「记一笔」跳转新增账单页，1s后返回首页，无限循环3min |
| 输出文件 | 02_页面切换_性能日志.csv |
| 数据表现 | 每次页面重建会创建新Compose宿主，页面栈对象回收存在延迟，内存基线小幅抬升 |

### 场景3：批量增删账单高频读写压力测试

| 项目 | 说明 |
| --- | --- |
| 自动化逻辑 | 每轮自动新增5条账单数据，完成后模拟批量删除，循环执行3min |
| 输出文件 | 03_增删账单_性能日志.csv |
| 核心现象 | 内存整体震荡上行，每轮操作峰值逐级抬高，GC无法完全释放临时数据与视图对象 |

### 场景4：空闲对照组

| 项目 | 说明 |
| --- | --- |
| 操作 | 应用停留在首页无任何操作，采集3min空闲内存 |
| 输出文件 | 04_空闲监控_性能日志.csv |
| 作用 | 作为基准参考 |

## 四、分图逐项解析

### 4.1 左上：内存使用趋势对比（单位 MB）

| 场景 | 表现 | 结论 |
| --- | --- | --- |
| 空闲基准（红线） | 稳定维持119~120MB | 应用基础常驻内存 |
| 滑动列表（蓝线） | 启动冲高至123MB，后回落至121~122MB | 仅列表加载时临时占用，GC可回收 |
| 页面切换（橙线） | 启动峰值125MB，全程基线121~123MB缓慢抬升 | 页面重建带来持续内存堆积 |
| 增删账单（绿线） | 全场景内存最高，稳定124.5~125MB | 存在渐进式内存泄漏风险 |

### 4.2 右上：CPU使用率趋势对比（单位 %）

| 场景 | CPU表现 | 结论 |
| --- | --- | --- |
| 空闲监控（红线） | 稳定10%~12% | 最低CPU负载 |
| 滑动列表（蓝线） | 稳定13%~14% | 列表渲染、图片解码持续占用 |
| 页面切换/增删账单 | 前期13%，后期降至11% | 后期缓存生效负载回落 |

> 阈值参考：绿色虚线 30% 为高负载警戒线，所有场景CPU均远低于警戒线，无CPU过载卡顿。

### 4.3 左中：帧率FPS趋势对比

（标准参考：红色虚线30FPS为流畅临界线，绿色虚线60为满帧标准。）

### 4.4 右中：Jank卡顿率对比

| 场景 | Jank率 | 结论 |
| --- | --- | --- |
| 滑动列表、空闲监控 | 几乎为0 | 无明显卡顿帧 |
| 页面切换、增删账单 | 采样后半段微小波动 | 整体卡顿风险低 |

### 4.5 左下：电池温度变化（单位 ℃）

- 四条曲线完全重合，全程稳定 25℃
- 各场景CPU、GPU负载均较低，不会引发设备发热、降频
- 功耗控制合格

### 4.6 右下：各场景平均性能柱状对比

| 场景 | 平均内存(MB) | 平均CPU(%) |
| --- | --- | --- |
| 滑动列表 | 122 | 12.2 |
| 页面切换 | 123 | 11.0 |

**横向规律：**

## 五、综合性能问题总结

### 5.1 现存性能缺陷

无严重风险点：CPU未过载、无明显Jank卡顿、电池无升温。

### 5.2 分场景优化优先级

| 优先级 | 场景 | 优化方案 |
| --- | --- | --- |
| ★ 最高 | 增删账单 | 复用列表数据对象，操作后清空临时数据集 |
| ★★ 次高 | 页面跳转 | 使用Compose导航复用页面实例，避免重复重建 |
| ★★★ 常规 | 数据库操作 | 批量读写异步化，移入协程后台 |

## 六、Appium自动化测试优缺点总结

### 优势

| 优势 | 说明 |
| --- | --- |
| 无人值守长时间加压 | 可模拟连续高频操作，复现渐进式内存泄漏 |
| 数据自动持久化 | CSV时序完整可量化，支持批量绘图 |
| 标准化可复现 | 便于优化前后对比回归 |

### 局限

| 局限 | 说明 |
| --- | --- |
| 指标粒度较粗 | 仅采集全局内存、宏观帧率，无法精准定位具体泄漏对象 |
| 操作精度有限 | ADB指令延迟，精度低于人工Profiler调试 |
